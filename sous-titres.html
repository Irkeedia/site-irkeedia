Sous-titres shorts

Une vidéo entre, une vidéo sous-titrée sort. Entièrement en local. Remplace un abonnement Submagic ou Veed — et surtout : les sous-titres sortent à la charte de la marque, pas à celle de l’outil.

La chaîne

Ce qui se passe

vidéo ─┬─ ffmpeg ──── audio 16 kHz mono
       │                    │
       │              whisper.cpp large-v3 + DTW
       │                    │
       │              mots horodatés  ──  lexique.json (corrections)
       │                    │
       │              découpage en cartons de 2–3 mots
       │                    │
       │              Chrome sans interface → PNG transparents
       │                    │
       └─────────── ffmpeg overlay ────────► vidéo sous-titrée

6 s
Rendu
10 s
Source
11 s en 1080×1920
Ratio
≈ 1 min 30 / min

Les cinq étapes sont indépendantes et la transcription est mise en cache : on peut refaire dix rendus de style sans jamais relancer Whisper.

Contrôle

Ce qu’on garde en main

Les cartons sont relisibles

La transcription sort dans un fichier de cartons qu’on peut relire et corriger avant de lancer le rendu.

Un lexique de corrections

Les noms propres et le vocabulaire de la marque sont corrigés automatiquement, une bonne fois pour toutes.

Le style est du CSS

Les cartons sont rendus par un navigateur : la typographie, les couleurs et les animations suivent la charte, sans passer par les gabarits d’un outil tiers.

Rien ne sort de la machine

Aucune vidéo n’est téléversée. Pas de compte, pas d’abonnement, pas de quota — et rien à expliquer sur le traitement des données.

Installation

Une seule commande

Un script d’installation pose ffmpeg et whisper-cpp via Homebrew, télécharge le modèle ggml-large-v3 (environ 3 Go), installe les dépendances Node puis lance un diagnostic.

Ensuite, traiter une vidéo tient en une ligne de commande.

Besoin d’une chaîne vidéo sur mesure ?

Transcription, incrustation, déclinaisons de formats — en local ou en pipeline.
